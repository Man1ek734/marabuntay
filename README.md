# MARABUNTA BOT

Bot Discord dla Marabunty na DreamLife RolePlay.

## Railway
Start command: `npm start`
Variable: `DISCORD_BOT_TOKEN` - wprowadz nowy token tylko w Railway Variables. Nie umieszczaj tokenu w repozytorium.

Bot ustawia status Online oraz nazwe i range MARABUNTA BOT, a takze probuje poprawic nazwy pozostalych rang na bez emotek, jesli ma uprawnienia.

Do nadawania rol bot musi miec uprawnienie Zarzadzanie rolami, a jego najwyzsza rola musi znajdowac sie powyzej edytowanych rol.
